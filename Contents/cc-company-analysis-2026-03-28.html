🏢 cc-company リサーチレポート

調査日: 2026-03-28 ／ 対象: Shin-sibainu/cc-company

1. cc-company とは

Claude Code に「仮想会社組織」を持ち込むプラグイン（MIT ライセンス）。
ユーザーは秘書に話しかけるだけで、TODO 管理・壁打ち・タスク振り分けが自動化される。

/plugin marketplace add Shin-sibainu/cc-company
/plugin install company@cc-company
/company  ← セットアップ開始

コンセプト

あなた → 秘書（常設窓口） → 各部署（仕事が増えたら秘書が提案して追加）

定義されている部署

部署担当領域ステータス
秘書室TODO管理・壁打ち・メモ・相談常設
PMプロジェクト進捗・チケット管理追加制
リサーチ市場調査・競合分析追加制
マーケティングコンテンツ企画・SNS追加制
開発技術ドキュメント・設計追加制
経理・営業・クリエイティブ・人事各業務領域追加制

生成されるファイル構成

.company/
├── CLAUDE.md       ← 組織全体のルール
└── secretary/
    ├── CLAUDE.md   ← 秘書の振る舞い定義
    ├── inbox/      ← クイックキャプチャ
    ├── todos/      ← 日次タスク管理
    └── notes/      ← 壁打ち・相談メモ

2. AGY プロジェクトとの比較

本質的な発想は同じ
cc-company の「秘書→部署」構造と、AGY の「ティア（窓口）→ユリ/リク（専門担当）」は同じアーキテクチャ。 うちは既に独自実装で同等の構造を持っている。
観点cc-companyAGY プロジェクト（現状）
窓口秘書（汎用）ティア（キャラクター付き）
専門担当部署（CLAUDE.md で定義）ユリ（Gemini CLI）、リク（Codex CLI）— 実際の別プロセス
エージェントの実体Claude Code 内のロールプレイ
（同一プロセス）		リアルな別 AI（Gemini、Codex）を CLI 呼び出し
設定方法.company/CLAUDE.md.claude/rules/ + .claude/skills/ + .claude/souls/
TODO 管理秘書室が担当（ファイルベース）TaskCreate ツール
壁打ち・メモnotes/ フォルダhandoff.md + memory/
キャラクター付けなし（汎用ロール）あり（ティア/ユリ/リク）

3. 可用性の評価

⚠ 導入メリットは薄い（競合リスクあり）
  • .company/ ディレクトリが .claude/ と別系統で管理が分散する
  • AGY の組織構造は cc-company より高度（実際の別 AI を呼び出す）
  • 秘書の役割はティアがすでに担っている
✅ 参考にできる点
  • inbox/ フォルダ — クイックキャプチャの発想。思いついたことをすぐ残す仕組みは AGY にあってもいい
  • 部署提案のトリガー設計 — 「仕事が増えたら秘書が部署追加を提案」というフロー。AGY でも新しいタスクパターンが増えたらスキル追加を提案する仕組みが作れる
  • シンプルなエントリポイント（/company） — 一つのコマンドで全体が動く設計思想は参考になる

4. サブエージェント化との兼ね合い

cc-company のエージェントは「同一プロセス内のロールプレイ」

部署は CLAUDE.md でペルソナを定義するだけで、実際に別プロセスが動くわけではない。
Claude Code が自分自身で「開発部署として答える」という動き。

AGY の orchestrate は「リアルな別 AI プロセスへの委譲」

Gemini CLI（ユリ）は実際に Google の AI が動く。Codex CLI（リク）は OpenAI が動く。
これは cc-company とは根本的に異なる——真のマルチエージェントアーキテクチャ。

観点cc-company の部署AGY の orchestrate
実行モデルClaude 単体でロールプレイ異なる AI が実際に動く
リサーチ精度Claude の知識範囲内Gemini の Web 検索 + SNS 情報
コスト同じトークン枠を使うGemini は別クォータ
スケーラビリティClaude のコンテキスト上限に依存並列実行でコンテキストを分散

5. 結論

AGY は cc-company を超えた構造をすでに持っている。

cc-company は Claude Code 単体で「組織っぽく動かしたい」ユーザー向けの良いスターターキット。
一方 AGY は実際の別 AI（Gemini/Codex）を呼び出す真のマルチエージェントシステムで、キャラクター付きで運用している。

推奨アクション：
cc-company のインストールは不要。ただし「inbox/ によるクイックキャプチャ」の発想は今後 .claude/ に取り込むことを検討してもよい。
