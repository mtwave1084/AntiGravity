目的: ソリティアXの投稿ネタ探し・日々の自己成長のため、各エージェントに「人格らしさ」を持たせる仕組みを AGY に導入する。

元ネタ: Copilot との設計セッション（session_integrated_summary.md）— 人格3層モデル、Behavior Packet、Reflection システム、判断重み等。

結論: 概念フレームワークは優秀だが、AGY の既存インフラに対しては抽象層を増やしすぎ。最小構成版に絞って段階導入する。

1. リクの adversarial-review 結果

Codex CLI (gpt-5.4) による構造分析・115K tokens 使用

総合判定 要修正

思想は通っているが、現行 AGY に対しては抽象層を増やしすぎ。「人格OS」を作りに行っていて、「ネタ探し精度」を上げる最短距離から外れ気味。

観点判定要点
1. ファイル構成部分衝突.claude/ は「触らない」ルールがあるが新設ディレクトリを追加。ハード矛盾ではないが破壊範囲見積もり不足。
2. rubrics.yaml 重み不十分モード補正キーがロール rubric に存在しない（creativity が yuri にない等）。補正後合計が 1.0 にならない。ユリの uncertainty 重みが実態に対して軽すぎ。
3. delivery_packet条件付き可codex exec にテキストとしては渡せるが、現行 wrapper は単一行プロンプト前提。複数行 YAML は引用符・改行で壊れやすい。
4. session-state 分離反対handoff.md が唯一の正。別ファイルを足すと「どちらが真実か」問題。主観量（confidence/rapport等）は更新根拠が弱く放置される。
5. Phase 分け順序逆価値が出るのは Phase 3（delivery_packet）なのに、Phase 1-2 で基盤投資が先行。
6. 過剰設計かなりある既存の souls + orchestrate + memory + handoff で大半カバー済み。主観ステート・内発的報酬・昇格閾値・ヒステリシスは理論は綺麗だが運用で更新されない。
7. 費用対効果低めX ネタ探しのボトルネックは最新性・一次ソース・相性判定であって、人格状態の精密管理ではない。
リクが提起した根本的な問い:
この設計の目的は「X投稿ネタ探しの改善」なのか、「将来の自律人格OS」なのか？
→ 両方だが、フェーズを分けて先に実利を出す方針で修正する。

設計原則

  • 既存を壊さない — 新ファイルは最小限、既存ファイルの拡張で対応

  content_creation:
    description: "X投稿・記事・台本"
    priorities: [creativity, user_alignment, novelty]
    caution: "事実確認を省略しない"

  implementation:
    description: "実装・ファイル操作"
    priorities: [safety, reproducibility, maintainability]
    caution: "差分最小を意識する"

  reflection:
    description: "振り返り・改善"
    priorities: [coherence, rigor, traceability]
    caution: "改善案は具体的な変更箇所まで落とす"

```

優先順位：{priorities}
出力形式：{output_contract}
```

※ YAML構造体ではなくプレーンテキスト prefix。現行 wrapper と互換性あり。

4. X投稿ネタ探しフロー（実利部分）

具体的な運用フロー

  1. ティアが content_creation モードを選択
  2. ユリに exploration prefix 付きでトレンド調査を依頼
    • 「ソリティアXに合うAI・テック・クリエイティブ系のネタを5件、novelty重視で探して。不確実な情報は明示すること」
  3. ティアが結果を受け取り、ソリティアXの方針と照合
    • キャラクター性との相性、鮮度、独自性をチェック
  4. 有望なネタをリクに渡して実現可能性チェック（必要な場合のみ）
  5. ティアが投稿案を 3パターン生成
  6. Discord にネタ一覧を送信、ソリスの GO を待つ

ティアの判断基準（定性版）

基準チェック内容
鮮度24時間以内のニュース・トレンドか？
独自性他のAI系アカウントが同じ切り口で出していないか？
キャラ相性ソリティアXの3人（ティア・ユリ・リク）のどのキャラで投稿するのが自然か？
エンゲージメントリプライ・引用RTが来やすいテーマか？
事実確認一次ソースが確認できているか？
