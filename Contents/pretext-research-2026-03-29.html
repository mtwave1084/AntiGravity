概要

Pretext は、元 Meta エンジニアの Cheng Lou（@_chenglou / ReasonML・ReScript の作者）が開発した、JavaScript/TypeScript 製の高性能テキスト計測・レイアウトライブラリ。

「画像や任意の形状にテキストが自動的に流れ込む」ような複雑なレイアウトを、DOMに頼らない独自の算術ロジックで超高速に実現する。

GitHub: chenglou/pretext ｜ デモページ

技術の原理・仕組み

DOM計測の問題点 課題

通常のブラウザは getBoundingClientRect や offsetHeight などの DOM API でテキストの高さ・位置を取得する。

この操作を呼び出すたびに レイアウト・リフロー（再計算）が強制実行され、ブラウザの最も重い処理の一つが走る。大量のテキストを扱うUIでは深刻なパフォーマンスボトルネックになる。

Pretext のアプローチ：DOM不要の独自計算 解決策

ブラウザのフォントエンジンを「正解データ（Ground Truth）」として使いながら、DOM計測を一切行わずに独自の算術ロジックでテキストを計算する。
機能 内容
テキスト高さ計算 最大幅・行高さを指定すると行数・高さを返す
手動ルーティング テキストを任意の形状（画像の輪郭・UIパーツ）に沿って流す
Shrinkwrap テキストが「最も狭い幅でも行数が変わらない」幅を自動計算
多言語・絵文字 双方向テキスト（Bidi）・絵文字・全言語に対応
出力先 DOM / Canvas / SVG / WebGL（SSR は近日対応予定）

📊 パフォーマンス実績：500件のテキストバッチ計算が 約 0.10ms で完了

実用性・活用法

既存CSSとの違い 比較

手段 できること できないこと
CSS float シンプルな左右回り込み 複雑な形状・動的変化
CSS shape-outside 静的な任意形状への回り込み リアルタイム再計算・大量処理
Pretext 動的・複雑形状・高速・全言語 SSR（近日対応予定）

主な活用シーン

• 仮想スクロール — 大量リスト表示。事前に正確な高さが分かるためスクロールが滑らか

• CLS対策 — ページ読み込み時のレイアウトシフト（ガタつき）を完全防止

• Masonryレイアウト — Pinterestのようなカード型グリッド

• 雑誌・editorial UI — 画像・広告・図解を含む複雑なテキストレイアウト

• リアルタイム計算が必要なUI — テキスト量・フォントが変わるたびにレイアウトを再構成

Remotion / 動画制作への応用 AGY関連

テロップや字幕が画像・キャラクターの輪郭に沿って動的に回り込む表現が実現できる。

Remotion（React ベース）と組み合わせると、フレームごとにテキストレイアウトを再計算しながらアニメーションさせることが可能になる可能性がある。

SSR 対応が完成次第、Node.js 側での事前レンダリングにも使えるようになる。

注意点・制約

• SSR：ドキュメントに「soon（近日対応）」と記載あり。現在はブラウザ環境のみ

• システムフォント：macOS の system-ui 等では計算精度が低下することがある。明示的なフォント指定を推奨

• 学習コスト：DOM の自動レイアウトから抜けて「手動でテキストを配置する」設計思想に慣れる必要がある
