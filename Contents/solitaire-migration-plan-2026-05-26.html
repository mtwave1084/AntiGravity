1. 背景と目的

現プロジェクトディレクトリ C:\Users\mt_wa\projects\agy は元々 AntiGravity の略として作成された。 だが Google が 2026-05-19 I/O で Antigravity 2.0（スタンドアロンのエージェントファーストアプリ）と Antigravity CLI を正式リリースし、サブスク利用が始まる。 略称「agy」が新CLI（Antigravity）とぶつかって紛らわしくなる。

また Gemini CLI は 2026-06-18 にサービス停止（Pro/Ultra/個人向け Code Assist 利用）。 あと3週間で Gemini CLI が使えなくなるので、Antigravity CLI への移行設計も同時に立てておきたい。

実体（ティア＋ソリス＝ソリティア）に合わせて Solitaire プロジェクトに改名するのは自然な選択。 本計画書はこの2件（プロジェクト改名 + CLI移行）を安全に進めるためのもの。

改名と CLI 移行は ほぼ独立だが、.claude/skills と rules は両方の変更対象。 1つの巨大変更にせず段階を分けるのが安全。並行実装は避ける。

4. 推奨実装ステップ

原則： 並行実装は避ける。設計は同時OKだが、実作業は「CLI互換層」→「rename」→「旧名整理」の順。

1現状スナップショット作成（read-only）

  • rg agy|AGY / rg gemini|Gemini の grep 結果を保存
  • .claude/projects/C--Users-mt-wa-projects-agy/ 全体のバックアップ（ZIP化推奨）
  • .git/config と .git/worktrees/infallible-solomon/ の参照を記録
  • CronList で現在登録されている cron を全部リスト

2Antigravity CLI 互換層の設計と試験（workspace-write）

  • Antigravity CLI のインストール・認証・コマンド構文を確認（公式ドキュメント）
  • consult-antigravity.ps1 を新設（consult-gemini.ps1 と同じインターフェース）
  • consult-gemini.ps1 を薄い互換ラッパーに改修（中身は antigravity 経由 or 旧 gemini 経由を選択可能に）
  • 手動疎通テスト：「ユリ、テストだよ」みたいな軽い問い合わせで動作確認

3スキル・ルールの記述切り替え（workspace-write）

  • .claude/skills/ai-news/SKILL.md の Step A を Antigravity 仕様へ
  • .claude/rules/orchestrate.md のモデル表・認証セクション再設計
  • .claude/skills/cli-maintenance/SKILL.md の更新確認対象を変更
  • memory/coding-agent-landscape.md を最新化

4Claude per-project ストレージ移行（workspace-write）

  • Claude Code を閉じる
  • C--Users-mt-wa-projects-agy/ を C--Users-mt-wa-projects-solitaire/ にコピー（memory + transcript）
  • 旧キーは削除せず一定期間保持

5settings.local.json 内の絶対パス更新（workspace-write）

  • Stop hook の C:\Users\mt_wa\projects\agy\scripts\on-stop.ps1 等を solitaire パスに置換
  • rename より 前に行う（rename後だと Stop hook が壊れた状態になる）

  • worktree infallible-solomon を先に prune または別途処理（worktree がある状態で親rename はNG）
  • Claude Code・全関連プロセスを停止
  • C:\Users\mt_wa\projects\agy → C:\Users\mt_wa\projects\solitaire にエクスプローラで rename
  • worktree を必要なら再作成

7スクリプト・スキル内の絶対パス置換（workspace-write）

  • scripts/*.ps1, *.bat の projects\agy → projects\solitaire
  • .claude/skills/ccc-*, .claude/workflows/filesystem-maintenance.md 内のパス文字列
  • 差分を Codex でレビュー（adversarial-review）

8呼称・命名の置換（workspace-write）

  • CLAUDE.md, AGENTS.md, GEMINI.md, .claude/handoff.md の「AGY プロジェクト」表現を Solitaire に
  • .claude/rules/mode-tags.md の [DEV-AGY] → 新タグ（Q4で確定）
  • JOBS.yaml、ai-news など skill ファイル内の言及

7. ロールバック手順（失敗時）

  1. Claude Code・関連プロセス停止
  2. projects/solitaire を projects/agy に戻す（rename 逆操作）
  3. C--Users-mt-wa-projects-solitaire/ を削除 → 旧 C--Users-mt-wa-projects-agy/ が残っているのでそのまま使える
  4. settings.local.json を git stash / git restore で旧版に戻す
  5. CronList で新規 cron を削除して ccc-jobs 経由で旧版を再登録

※ 旧 per-project storage を削除しないのが安全弁。
