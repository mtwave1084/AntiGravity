🎙️ Gemini 3.1 Flash Live — 調査レポート 2026-03-27

📌 概要

Gemini 3.1 Flash Live とは

Google が2026年3月26日にプレビュー公開したリアルタイム音声対話専用モデル。テキストを介さず音声から直接音声を生成（Audio-to-Audio）することで超低遅延を実現。Gemini Live および Search Live に統合されている。

「これまでで最も高品質な音声・音声モデル」— Google 公式。会話の割り込み・自然なテンポ・背景ノイズ除去が最大の特徴。

主な仕様

項目内容
モデルIDgemini-3.1-flash-live-preview
コンテキストウィンドウ入力 128K トークン / 出力 64K トークン
対応言語90言語以上のリアルタイム対話
入力音声（16ビットPCM 16kHz）・画像（JPEG 1FPS）・テキスト・動画
出力音声（16ビットPCM 24kHz）・テキストトランスクリプト
接続プロトコルWebSocket（双方向ストリーミング）
提供形態プレビュー / Google AI Studio / Gemini Live API

前モデル（Gemini 2.5 Flash Native Audio）からの改善点

  • 応答遅延がさらに低下（体感的に自然な会話テンポ）
  • 背景ノイズ・ピッチ・テンポなど音響的ニュアンスの認識精度向上
  • 会話スレッド維持長が従来の 2倍
  • 複雑なシステム指示への遵守率向上
  • 全音声出力に SynthID 電子透かし（聞こえない形で埋め込み）

🛠️ APIの使い方

SDK セットアップ

pip install -U google-genai  # v1.56.0以降推奨

基本的なリアルタイム音声対話（Live API）

import asyncio
from google import genai
from google.genai import types

client = genai.Client(api_key="YOUR_API_KEY")

async def main():
    # Live API は WebSocket 接続
    async with client.aio.live.connect(
        model="gemini-3.1-flash-live-preview",
        config={"response_modalities": ["AUDIO"]}
    ) as session:
        # 音声データ（16bit PCM 16kHz）を送信
        await session.send(input=audio_bytes, end_of_turn=True)
        # 音声レスポンスを受け取り（24kHz PCM）
        async for response in session.receive():
            if response.data:
                play_audio(response.data)

asyncio.run(main())
Live API は通常の generate_content ではなく client.aio.live.connect() を使う。WebSocket 双方向ストリーミングが前提。

💻 Gemini CLI から使えるか？

条件付き可

  • Gemini CLI（ターミナルの gemini コマンド）は テキストモード が基本
  • gemini-3.1-pro-preview や gemini-3-flash-preview は -m フラグで指定して 使用可能
  • gemini-3.1-flash-live-preview は 音声WebSocketモデル のため、テキストベースのCLIとは相性が悪い
  • 音声入出力が必要なので、CLI から直接リアルタイム会話はできない
  • テキスト入力・テキスト出力に限れば Live API へのアクセス自体は API キーで可能
✅ テキスト調査・リサーチ → gemini -m gemini-3.1-pro-preview -p "..." で使える
❌ リアルタイム音声対話 → CLI ではなく Python/Node.js + WebSocket で実装が必要

🎯 私たちで使えそうなユースケース

🎵 楽曲・MV 制作のコメンタリー

制作中の音楽やMV映像をリアルタイムで流しながら、Flash Liveに「今の部分どう思う？」と話しかける。音楽制作の壁打ち相手として。

🤖 Discord ボイスチャンネル統合（実験）

Discord Bot にLive APIを組み込んでボイスチャンネルで会話できるティアを作る。WebSocket → Discord Audio の橋渡しで実装可能。

🎙️ 動画台本の読み合わせ

ソリスとティアの対話形式台本を、実際に音声で読み合わせてリズム・テンポを確認。テキストより感覚的にチェックできる。

📸 カメラ映像リアルタイム解析

カメラ映像（1FPS）を送りながら音声で質問。「今写ってる場所どこだと思う？」のような使い方。以前の桜写真解析の音声版。

🌐 多言語リアルタイム翻訳

90言語対応。日本語で話しながら英語出力させるリアルタイム通訳。海外コラボや字幕自動生成のプロトタイプに。

🔬 実験的な AI 音声キャラクター

ティアの音声版プロトタイプ。テキストベースの会話だけでなく、声で話すティアを試作する足がかりになる可能性。

📋 総評と推奨アクション

まとめ

Gemini 3.1 Flash Live は「音声でリアルタイムに話しかけてリアルタイムに返答が返ってくる」ことに特化したモデル。テキスト生成AIとは根本的に異なる使い方をする。

コストは 音声通話として考えると$0.023/分（約3.5円/分） とそこまで高くない。Gemini 3.1 Pro のテキスト処理より特定用途では安い。

推奨アクション：

  • まず Google AI Studio のプレイグラウンドで音声対話を試してみる（無料枠あり）
  • Discord ボイスbot との統合は Python + websockets ライブラリで実装可能
  • CLIから使うなら gemini-3.1-pro-preview が現実的（テキスト系タスク向け）
  • 音声ティアの実験には有望だが、Discord オーディオ処理の実装コストは別途かかる
