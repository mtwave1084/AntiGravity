🔧 テーマ1：Obsidian × Claude Code の組み合わせ事例

事例概要有効度AGY可用性
① obsidian-claude-code-mcp WebSocket（port 22360）で Claude Code と Vault を直接繋ぐ MCP ブリッジ。Vault が作業ディレクトリでなくても Claude がノートを読み書きできる 高 ◎
② Agent Client プラグイン Obsidian のサイドパネルから Claude Code / Codex / Gemini CLI をチャット形式で操作。ターミナル不要で Vault 内から完結 中 △
③ Vault ルートに CLAUDE.md Vault ルートに置いた CLAUDE.md がセッション毎に自動読み込み。「毎回コンテキストを渡す手間」ゼロ 高 ○（既に類似構成）
④ フラットなファイル構造 深いフォルダ階層はパス解決にトークンを消費するため、なるべくフラットに。ファイル名を文章形式にすると Claude がパスだけでコンテキストを得られる 中 △
⑤ Skills を Vault 上位ディレクトリに 複数 Vault を持つ場合、`.claude/skills/` を Vault の一段上に置くと全 Vault から共通スキルを呼べる 低 不要
⭐ AGY 最推奨: obsidian-claude-code-mcp（①）
現状の Claude Code から Obsidian ノートを読み書きするには直接ファイルパスを指定する必要があるが、このプラグインを入れると Vault のどのノートでも自然に参照できる。 heartbeat での `99_Insights` 書き込みがより安定する。

🤖 テーマ2：Obsidian × AI 自動化（日本語事例）

事例概要有効度AGY可用性
⑥ Hook で全会話を Obsidian に自動記録 Claude Code の Hook 機能で、Claude との全会話を自動的に Obsidian ノートへ書き出す。User/Assistant セクションに自動分類。ナレッジが会話の中に自然に蓄積される 高 ◎
⑦ MCP 多連携で朝ルーティン自動化 Gmail・Google Calendar・Notion・Slack などを一括統合。毎朝のタスク整理を30分→3分に短縮した実例 中 △
⑧ 記事執筆の完全自動化パイプライン Claude Code × Obsidian でインタビュー形式の質問 → 文章生成 → AI表現検出・修正 → 投稿まで自動化 中 △（Brain記事に応用可）
⑨ 対話型ジャーナリング 単なる記録を脱却し、過去ノートを MCP で渡して Claude との対話で思考を深めるジャーナリング手法 高 ◎（ソリス向け）
⑩ Claudesidian（統合プロジェクト） Obsidian と Claude を完全統合するオープンソース。フォルダ構造・ワークフロー・カスタムコマンド・自動化スクリプトをパッケージ提供 低 重すぎる可能性
⭐ AGY 最推奨: Hook で全会話を自動記録（⑥）
Claude Code の Hook（PostToolUse / Stop）を設定するだけで、ティアとの会話が Obsidian に自動保存される。
現状の handoff.md + memory/ を補完し、Obsidian から会話履歴を参照できるようになる。

📚 テーマ3：Obsidian PKM の実践的な使い方

事例概要ソリス向け評価
⑪ 最小フォルダ＋階層タグ フォルダは最小限、タグを `#親/子/孫` 形式で階層化。MOC ノートで入口を作れば深いフォルダ階層は不要 中 — 今のPARA構造は複雑すぎるなら検討
⑫ Odysseas 式（思考ライフサイクル型） Inbox → Rough Notes → Source Material → Permanent Notes → Projects という思考の流れに沿った構成 中 — PARAより直感的だが移行コストあり
⑬ 「頑張らない」Obsidian 完璧な構造より「書き続けること」を優先。Inbox に何でも放り込み、週次レビューで整理するゆるいフロー 高 ← 今のソリスの状況に最適
⑭ ツェッテルカステン 「永続ノート」に自分の言葉で再記述し、リンクで繋いでネットワーク化。読書メモ→自分の考えに昇華するフロー 低 — 手間がかかるため今は不向き
⑮ Ark フォルダ構成 Archive / Resources / Knowledge の 3〜4 フォルダに集約。PARAの簡略版として日本のブロガーに広まっている 中 — PARAが重く感じるなら代替として検討
⚠ 今のソリスの状況への提言：「頑張らない」が最適解
PARA を完璧に使おうとするより、LINE → Inbox に放り込む仕組みだけを維持して、整理は気が向いたときだけでOK。 整理はティアに「Obsidian の Inbox 整理して」と言えば Claude Code がやれる。
