3. 設計哲学：Self-contained 原則

最重要原則：「.claudeフォルダだけを渡せば、受け取った人が同じ動画制作挙動を再現できる」

ユニコの .claude/ は「AIエージェントの設定集」を超えて、ZIPで配布可能なワンパッケージ製品として設計されている。Brain という販売形態（購入→ダウンロード→即使用）に最適化した構造。

Self-contained の実装方法

要素方法
BGMresources/bgm/に同梱。setup.sh が自動コピー
スタイル資料resources/style-catalog.* + 30枚サンプル同梱
プロジェクト骨格scaffold/ に Remotion テンプレート全体を同梱
APIキー管理.env.example にフリーモデルID同梱、実キーは skills-demo/.env のみ
セキュリティ配布前チェック（シークレット検索・個人情報・ファイル数確認）を distribute-zip スキルに内包

simple-manga-video の4ステップ確認フロー

STEP 1 🎨 スタイル選択 + 素材生成
HTML確認: style-catalog.html（30スタイルから番号選択）→ TTS音声 + 画像生成
STEP 2 👀 レンダリング前確認
HTML確認: preview-[動画名].html（速度切替ボタン 1x/1.5x/2x 付き）
STEP 2.5 🔧 修正確認（修正があった場合のみ）
HTML確認: fix-check-[動画名].html（修正前後 diff + 音声再生 + OK/NG）
STEP 3 📝 字幕レビュー（レンダリング前必須）
HTML確認: subtitle-review-[動画名].html（BGM付き最終確認）
STEP 4 🎬 レンダリング + 完成動画
HTML確認: completion-[動画名].html（SEOタイトル5案 + ダウンロードボタン）

設計ポイント：各ステップでHTMLを生成してユーザー確認を挟む。STEPスキップは絶対禁止。全自動でありながら「人間が確認する箇所」を明確に定義した設計。

AGY固有の注意が必要なもの ⚠️

fal.ai APIコスト：$0.15/image〜（解像度で変動）。積極利用する場合は月次費用を試算すること
Fish Audio ボイスクローニング：自分の声を使う場合は Fish Audio に別途音声データを登録が必要
Remotion音声処理：playbackRate 使用禁止 → 事前 ffmpeg 変換必須。忘れると音声途切れが発生
APIキー管理：Fish Audio + fal.ai の2つが必要。.env は .claude/ に絶対に含めない

7. 運用上の注意事項

音声関連（重要度：高）

#ルール
1Remotionの音声速度変更は playbackRate 禁止 → 事前に ffmpeg で変換
2速度設定を変えた場合は全音声を削除して全件再生成（fs.existsSync でスキップされるため部分再生成は二重変換を起こす）
3音声パスは public/audio/ — out/audio/ を変換しても無効
4フレーム数計算 = Math.ceil(変換後秒数 × 30) + 5

画像生成関連

#ルール
1デフォルトのアスペクト比は 9:16（縦）。横動画の場合のみ 16:9 に変更
2スタイルカタログのプロンプトをそのまま使わない → STYLE + CHAR + シーンプロンプトの3定数体制が必須
3fal.ai 残高切れは Forbidden エラーで検出できる

設定ファイル関連

#ルール
1settings.json の defaultMode に "ask" は無効値 → Claude Code 起動エラーになる
2個人ボイスID (FISH_AUDIO_REFERENCE_ID) は .claude/ に書かない — ZIP配布に含まれるため

配布前チェック（distribute-zip 実行時）

6項目チェック：① シークレット検索 ② サンプル画像30枚確認 ③ BGM確認 ④ APIキー実値なし確認 ⑤ 個人情報検索 ⑥ HTMLテンプレート4種確認

9. 特筆すべき発見

🔍 Nanobanana Pro = fal-ai/gemini-3-pro-image-preview via fal.ai

ユニコの CLAUDE.md に画像生成のモデルIDが明記されていた：

モデル: fal-ai/gemini-3-pro-image-preview
プロバイダー: fal.ai（2026年2月1日より）
コスト: $0.15/image〜
解像度: 2K（デフォルト）

ソリスが「Nanobanana Pro」と呼んでいた画像生成エンジンの実体は fal.ai 経由の fal-ai/gemini-3-pro-image-preview。

ユリ（Gemini CLI）は直接呼び出せないが、AGYに fal.ai 統合を追加すれば Claude Code（ティア）から直接呼び出せる。

fal.ai の API キー取得 → skills-demo/.env の FAL_KEY を設定するだけで利用開始可能。
