## コアコンセプト

> 「影は、光が作れた道を示すべ。その先に、きっと星が待っている。」

月の位置を操作することで地上に落ちる影が変化し、その影が「実体を持つ足場」として出現する——これが本ゲームの中心にある体験。

**天体を操作して足元の物理法則を書き換える。神話的な感覚を、プレイヤーの手で体感させる。**

---

## コアメカニクス：シャドウ・パス

### 基本操作

| 操作 | 入力 |
|------|------|
| キャラクター移動 | 左スティック / WASDキー |
| 月の位置を動かす | 右スティック / マウス（リアルタイム） |

### シャドウ・パスの仕組み

1. プレイヤーが右スティック/マウスで月の位置をリアルタイムに動かす
2. 月の光の角度に応じて、木・岩・水面などの影が地面に落ちる
3. 影が特定の形・位置に「はまった」瞬間、その影が実体を持つ足場（シャドウ・パス）に変化する
4. 足場が確定した瞬間、低いピアノのSEが1音鳴る

### 操作補助

月を動かしている間、キャラクターは自動で静止する。月操作と移動の同時入力は求めない。

## ゲームの進行

### エリア構成

```
麓：はじまりの光
  └─ チュートリアル。密な森。一本の木の影を伸ばして川に橋をかけるだけ。

中腹：滝つぼの谷
  └─ 水面・滝が登場。水面への反射光で影を作る要素が追加。
     月の角度によって反射点が変わるため、映し方を考える必要が出てくる。

八合目：風の盆地
  └─ 揺れる木の影をタイミングで使う。
     雲が月を遮る瞬間に道が消えるギミックが登場（消える直前に渡る）。
     風で影が不安定に揺れる。

頂上直下：星の階段
  └─ 複数の光源・鏡岩が登場。
     春の大三角形（アークトゥルス・スピカ・デネボラ）に対応する鏡岩が3つある。
     月を特定の高度に固定すると鏡岩が月光を反射して、空へ伸びる光の道ができる。

頂上：星降る峰（クライマックス専用舞台）
  └─ 通常エリアとは独立したクライマックスの舞台。
     光の道を駆け上がり、アークトゥルス・スピカ・デネボラの3つの星を順に触れると——
     山全体が新緑の輝きで満たされる。
```

### クライマックスの流れ

1. 頂上直下で3つの鏡岩を正しい角度で照らす
2. 鏡岩が一斉に月光を反射し、空へ伸びる光の道が出現
3. プレイヤーがその道を駆け上がる
4. 春の大三角形の3星（アークトゥルス→スピカ→デネボラ）を順に触れる
5. 山全体が新緑の光で満ちるエンディング

## 体験設計

### 感情の流れ

```
静けさ（麓）
  → 知的な楽しさ（中腹〜八合目）
    → 月と繋がる神秘感（頂上直下）
      → 解放感（頂上）
```

### テンポの設計

- **急かさない。** スタミナゲージなし、時間制限なし。
- プレイヤーが自分のペースで呼吸しながら進める。
- 影がシャドウ・パスにはまる瞬間だけ、低いピアノのSEで「正解」を知らせる。
- BGMはアンビエント系。月の高度に応じて微妙にトーンが変化する（設計検討中）。

## UI・情報設計

### 日誌

- プレイ中に訪れたエリアとヒントが自動記録される
- 春の大三角形の星座図がクライマックスの伏線として日誌に記録される
- タイトル画面でも春の大三角形（アークトゥルス・スピカ・デネボラ）の星座線が空に描かれており、ゴールが最初から示されている

### HUD

- 進捗ゲージ（%表示）
- 現在の目標テキスト
- プレイ時間
- L/Rスティックの操作ガイド（画面下部に常時表示）

## 確認・検討事項

| 項目 | 状況 |
|------|------|
| 月操作とキャラ移動の同時操作難易度 | アシスト（月操作中に自動停止）で対応する方針だが試作が必要 |
| BGMの月連動仕様 | 要詳細設計 |
| プラットフォーム・エンジン | ブラウザ対応優先のため、WebGL対応エンジン（Godot / Unity WebGL / Phaser等）を要選定 |
| 使用する星座の統一 | 春の大三角形（アークトゥルス・スピカ・デネボラ）に統一。夏の大三角（ベガ・デネブ・アルタイル）は混在させない |
