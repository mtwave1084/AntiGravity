Claude Code

v2.1.116 で品質低下バグ3件を修正 — 全サブスクライバーの使用制限もリセット アップデート

Anthropic が過去1ヶ月にわたる Claude Code の品質低下問題に関するポストモーテムを公開。原因は3つの製品変更の複合: ①3月4日に UI レイテンシ対策として推論レベルをデフォルト「high」→「medium」に変更（Sonnet/Opus 4.6 の知性低下）、②3月26日に長時間アイドルセッションの古い思考ブロックを刈り込む最適化に入ったバグ（毎ターン発火し続けセッション全体を劣化）、③4月16日に冗長性削減プロンプトを追加（コーディング品質に悪影響）。すべて v2.1.116（4月20日）で修正済み。あわせて全サブスクライバーの使用制限が 4月23日付でリセットされた。

Google Ironwood TPU（第7世代）発表 — Anthropic が最大100万ユニット導入予定 ハード

Google が第7世代 TPU「Ironwood」を発表。1チップあたり 4.6 PetaFLOPS を実現し、9,216チップのスーパーポッド構成では 42.5 ExaFLOPS のコンピュート能力を提供。前世代 Trillium の約3倍の演算性能を持つ。Anthropic が Google Cloud 上で最大100万ユニットの Ironwood 導入にコミットしており、Google の最大顧客の一つとなることが明らかになった。AI 推論・学習インフラとして 2027年以降の本格稼働を見込む。
