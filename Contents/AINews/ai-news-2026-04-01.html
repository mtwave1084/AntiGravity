Claude Code ソースコード漏洩 — npm .map ファイルから51万行が流出 セキュリティ

2026-03-31、npm レジストリの @anthropic-ai/claude-code@2.1.88 に 59.8MB の JavaScript ソースマップファイルが誤って同梱されていたことを Solayer Labs のエンジニアが発見。TypeScript 換算で約 512,000 行の内部コードが数時間で GitHub にミラーリングされ数千人に解析された。

漏洩で判明した未公開機能：

  • KAIROS — 常時起動型アシスタント。タイピングを待たず、ログを監視して自律的に行動する
  • BUDDY — 固有の人格を持つ相棒 AI。名前で呼びかけると応答する
  • ULTRAPLAN — 30分間のリモートプランニングセッション
  • エージェントスウォーム / coordinator モード

コード内に 4月1〜7日をティーザー期間、5月を本格ローンチとするスケジュールが記載されていた。
