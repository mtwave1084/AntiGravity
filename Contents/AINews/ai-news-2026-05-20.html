Gemini Omni Flash 公開 — 推論×生成の新モデルファミリー 新モデル

Gemini Omni は推論能力と生成能力を統合した新モデルファミリー。画像・音声・動画・テキストを入力し、実世界の知識に基づいた動画を出力・編集できる。第一弾の Gemini Omni Flash は本日（5/20）より Gemini アプリ・Google Flow・YouTube Shorts で利用可能。

Gemini Spark 正式ローンチ — 24時間個人エージェント 新機能

AntiGravity / 開発ツール

AntiGravity 2.0 — VS Code ラッパーから脱却したスタンドアロンエージェントアプリ 大型アップデート

Google が AntiGravity 2.0 を Google I/O 2026 で正式発表。従来の VS Code ベースのラッパー構造を廃し、エージェントファーストのスタンドアロンアプリとして全面再設計された。複数サブエージェントの並列実行・バックグラウンドタスク・SDK も同時リリース。Claude Code・Codex CLI と同じ「コーディングエージェントアプリ」の競合ポジションを明確化。Gemini 3.5 Flash を内部で使用して開発されたことも言及。

Gemini CLI → Antigravity CLI 移行（6月18日） 要対応

現行の Gemini CLI は 2026年6月18日にリクエスト停止。Google AI Pro/Ultra・無料ユーザーすべてが対象。移行先の Antigravity CLI は agent skills・hooks・subagents・extensions（プラグイン名義）を引き継ぐ設計だが、完全な機能パリティは未達。公式 npm パッケージは現時点（5/20）未公開。

⚠️ Gemini CLI を使っている場合は6月中旬までに移行確認が必要
