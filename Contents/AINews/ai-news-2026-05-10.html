OpenAI — ChatGPT 自己サービス型広告プラットフォーム（Ads Manager）始動 企業動向

OpenAI が ChatGPT への自己サービス型広告購入を開放（2026-05-05〜06）。セルフサービス広告 Ads Manager を米国で先行ロールアウトし、Dentsu・Omnicom・Publicis・WPP などのエージェンシーパートナー経由でも出稿可能に。CPC（クリック課金）入札に対応し、これまでの最低出稿額 $50,000 の撤廃を表明。Conversions API とピクセルベースの計測ツールも導入し、広告経由の購入・リード等のコンバージョン追跡が可能に。今後数週間で英国・ブラジル・日本・韓国・メキシコへの展開テストを開始。OpenAI の今年の広告収益目標は $25 億（一次ソース確認推奨）。

2026-05-05〜06（Axios, OpenAI 公式, Digiday 報道）

ChatGPT — Trusted Contact（緊急連絡先）機能追加・Plus/Pro 向けメモリ強化 新機能

ChatGPT が2つの新機能を展開（2026-05-09）。①「Trusted Contact」：自殺・自傷関連の深刻な懸念を自動検出した場合に、ユーザーが事前に設定した信頼できる連絡先へ通知する安全機能。設定から任意でオンにする形式。②「Memory Sources（メモリソース）」：Plus・Pro ユーザー向けに、過去のチャット・保存済みメモリ・ファイル・連携済み Gmail の内容を組み合わせてパーソナライズした回答を生成できるよう強化。どの情報が回答に使われたかの表示や編集も可能。Memory Sources は全 ChatGPT コンシューマープランへの段階展開も予定。

Anthropic

Claude Security — コード脆弱性スキャン公開ベータ（Opus 4.7 搭載） 新機能

Anthropic が「Claude Security」の公開ベータを Enterprise 顧客向けに開始（2026-05-01〜04）。Claude.ai 上でコードベース全体をスキャンし、脆弱性の検出・パッチ案の生成・修正の説明を提供する機能。Opus 4.7 モデルを使用し、信頼度・重大度・再現手順・影響を詳述したレポートを出力。スケジュールスキャン・特定ディレクトリ指定・CSV/Markdown エクスポート・Slack/Jira/Webhook 連携など運用統合機能も搭載。連携テクノロジーパートナーは CrowdStrike・Microsoft Security・Palo Alto Networks・SentinelOne・TrendAI・Wiz。Team・Max 顧客への展開は今後予定。

2026-05-01〜04（Help Net Security, IT Pro, DevOps.com 報道）

Google Home Spring 2026 Update — Gemini 3.1 搭載・カメラUI大幅刷新 新機能

Google が Google Home の Spring 2026 アップデートを公開（2026-05-05）。主要アップデートは2点。①「Gemini for Home」の音声アシスタントが Gemini 3.1 にアップグレードし、複雑な多段階の音声コマンドを1回の発話で処理できるようになった（例：複数デバイスの連動制御・スケジュール設定を一括実行）。アーリーアクセスユーザーへのロールアウト完了。②カメラアプリUIを全面リニューアル——高速ナビゲーション・スムーズな動画スクラブ・ズームインプレビュー付きアラート・イベント詳細画面の再設計。同時に Web インターフェースの新UIも追加。
