Anthropic × ゲイツ財団 $200M 提携 — グローバルヘルス・教育・農業に AI を展開 企業動向

Claude Code

Claude Code 2.1 — Agent View & /goal コマンドで並列エージェント運用が本格化 新機能

5月11日リリースの v2.1.139 で Claude Code に2つの大型機能が追加された。Agent View（Research Preview）は、実行中・入力待ち・完了済みを問わず全セッションを1画面で管理できる CLI ダッシュボード（claude agents コマンドで起動）。/goal コマンドは完了条件を設定するだけでエージェントが複数ターンにわたり自律実行し、経過時間・ターン数・トークン数をオーバーレイ表示。interactive / -p / Remote Control の各モードに対応。同リリースには /plugin details（コンポーネント一覧とトークンコスト表示）・/scroll-speed・MCP 拡張なども含まれる。これにより1人の開発者がバグ修正・テスト・レビューを並列エージェントに分担させるワークフローが現実的に。

動画生成

Runway Gen-4 ローンチ — ネイティブ音声・キャラクター固定・ハイブリッドパイプライン対応 新モデル

5月3日、Runway が Gen-4 を正式リリース。最大の新機能はネイティブ音声生成で、動画と同時に音声トラックを生成する。キャラクター固定機能は参照画像3枚でアイデンティティをロックし、複数カットを通じて外見の一貫性を維持。新 API フックによるハイブリッドパイプラインでは Kling 3.0・Veo 3.1・VO3 AI など他社モデルと組み合わせて特定シーンに最適なモデルを選択できる柔軟な制作フローが可能に。Runway プラットフォーム内では Kling 3.0・Sora 2 Pro なども統合済み。Video Arena では Gen-4.5 が現時点1位を記録。
