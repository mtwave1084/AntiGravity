Anthropic × Google — 5年で $2000億のクラウド・TPU 支出契約を締結 企業動向

Anthropic が Google クラウドおよび Broadcom の TPU（Tensor Processing Unit）に対し、5年間で総額 $2000億（約30兆円）を支出する契約を締結したと The Information が報道（2026-05-05）。TPU 容量は複数ギガワット規模で 2027年から段階的に稼働開始。Alphabet は別途 Anthropic に最大 $400億を投資しており、Google との関係はコンピュート調達・投資・モデル展開の三層構造となる。Anthropic は SpaceX Colossus 1（GPU・短期）・AWS（$1000億超・10年）・Google（TPU・長期）と三方向でコンピュート基盤を確保する戦略。Anthropic の支出はGoogleが開示したクラウド売上残高の40%超を占めるとも指摘されており、AIスタートアップの規模が大手クラウドの収益構造を左右する局面になってきた。

OpenAI × PwC — AI ネイティブ財務機能を共同開発、CFO 業務をエージェントで再設計 新機能

OpenAI と PwC が提携し、企業の CFO 業務全体を AI エージェントで再構築する「AI ネイティブ財務機能」を発表（2026-05-05）。計画・予測・調達・支払い・財務クローズ・税務・レポーティングにわたる中核ワークフローを AI エージェントが人間の監督のもとで実行・調整する仕組みを構築する。まず OpenAI 自社の財務チームで調達エージェントを試験的に実装し、成果を検証しながら他企業への展開を進めるモデルを採用。PwC が財務変革・内部統制・実装ノウハウを、OpenAI がモデル・製品能力を提供する役割分担。財務 SaaS（ERP・FP&A ツール等）との統合も対象で、既存システムをそのまま活かしながらエージェント層を載せる設計とした。

Gemini API — マルチモーダル File Search 対応：画像とテキストを同一ストアで検索・引用 新機能

Google が Gemini API の File Search ツールをマルチモーダル対応に拡張（2026-05-05）。Gemini Embedding 2 モデルを採用し、テキスト文書と画像（チャート・製品写真・図表等）を同一ストアにネイティブにインデックス化して横断検索できるようになった。すべての回答に文書・ページ単位のグラウンディングメタデータが付与され、マルチモーダルストアではダウンロード可能な画像参照も引用として含まれる。Retrieval-Augmented Generation（RAG）アプリケーションの構築コストを大幅に下げる機能で、カスタムメタデータによるフィルタリングにも対応。合わせてページレベルの引用機能も追加された。

Gemini API — Event-driven Webhooks 導入：長時間ジョブのポーリング不要化 新機能

Google が Gemini API にイベント駆動型 Webhooks を追加（2026-05-04）。これまで長時間の生成・エージェント処理ジョブの完了確認には継続的なポーリングが必要だったが、新機能ではジョブ完了の瞬間に開発者のサーバーへ HTTP POST で即時通知を送信するプッシュ型に切り替わる。Google は「少なくとも1回の配信」を保証し、最大24時間の指数バックオフ自動リトライを実施。コードが "are you done?" を繰り返す非効率なポーリングが不要になり、長時間タスクを含む AI ワークフローのアーキテクチャがシンプルになる。エンドポイント設定後はリアルタイムペイロードを受け取るだけでジョブ完了を検知できる。
