Anthropic / Claude

Claude Opus 4.8 正式リリース — Dynamic Workflows・Fast Mode・正直さ向上 新モデル

5/28 に Anthropic が Claude Opus 4.8 をリリース。SWE-bench Pro 69.2%（4.7 の 64.3% から上昇）、USAMO 2026 は 96.7%（4.7 の 69.3% から大幅向上）。コードの欠陥をスルーする確率が 4.7 比 4分の1 に改善し、不確実な点を自発的に報告するようになった。料金は 4.7 と同じ（$5/$25 per 1M tokens）。

2026-05-28

Dynamic Workflows（リサーチプレビュー）— 最大1,000サブエージェント並列実行 新機能

Claude Code（Max・Team・Enterprise プラン）で利用可能な新機能。Claude がタスクに応じた JavaScript オーケストレーションスクリプトを自動生成し、最大 16 並列・1,000 サブエージェント をバックグラウンドで実行する。相互に反証するアドバーサリアルエージェントも含めて独立した角度から問題を攻撃し、答えが収束したら報告する設計。

2026-05-28

Fast Mode が 3倍安く — 2.5倍速で $10/$25 per 1M tokens 値下げ

Opus 4.8 の Fast Mode は 旧モデル比 3倍安い（$10/$25 per 1M tokens）。Opus レベルの品質を維持しながら 2.5倍速で動作。Claude Code の /fast コマンドでトグル可能。Messages API の mid-task system messages 対応も同時追加。

2026-05-28

「Mythos」クラスモデルが数週間以内に登場の見込み 予告

Anthropic は Opus 4.8 発表時に「Mythos クラスのモデルは数週間以内」と言及。4.8 はその手前のアップグレード位置付けで、能力的に Mythos に及ばないことを認めている。Claude Code では Opus 4.8 + Dynamic Workflows で数十万行規模のコードベース移行（テストスイートを完了条件に設定）が可能になった。
