Google / Gemini

Google I/O 2026 開幕 — Android XR スマートグラスを正式プレビュー、Samsung・Warby Parker・XREAL 等4社とハード協業 ハード

Google I/O 2026（5/19〜20）が開幕。基調講演（PT10時・JST5/20 02:00）に先立ち、Android XR スマートグラスを正式プレビュー。Gemini 2.5 Pro を搭載し、カメラ・マイク・スピーカーを内蔵。オプションのインレンズディスプレイでリアルタイム翻訳・ナビ・メッセージングを提供。ハードパートナーは Samsung・Warby Parker・Gentle Monster・XREAL の4社で、Samsung は今年中に Galaxy Glasses を発売予定。基調講演では Gemini Omni（ネイティブ映像×音声統合モデル）・Gemini Spark（24時間自律エージェント）・Googlebooks（Android ラップトップ）・Android 17 の詳細発表が見込まれる。

Google Vids × Veo 3.1 — 全アカウント無料解放・Lyria 3 AI音楽・AIアバター を I/O で発表 新機能

Google が I/O 2026 に合わせて Google Vids の大型アップデートを発表。これまで有料プランに限定されていた Veo 3.1 による動画生成が全 Google アカウントで無料利用可能に。Lyria 3（Google の音楽生成モデル最新版）によるカスタム AI 音楽生成、完全操作可能な AI アバターも同時追加。Veo 3.1 は 4K・最大8秒・ネイティブ音声生成対応。Veo 4 は2026年内にリリース予定とされ、より長尺・より高解像度・より精度の高いオーディオを目標としている。

Anthropic / Claude

Anthropic がビジネス採用率で OpenAI を初逆転 — Ramp AI Index、Claude Code が GitHub コミットの4% を生成 企業動向

Ramp（米コーポレートカード企業）が5月13日に公開した AI Index で、Anthropic のビジネス採用率が初めて OpenAI を上回ったことが明らかになった。2026年4月時点でAnthropicは34.4%（前月比+3.8%）、OpenAI は32.3%（前月比−2.9%）。Anthropic は2023年6月の0.03%から3年以内に34%超まで拡大しており、過去1年で採用率を4倍に伸ばした。けん引役は Claude Code で、全 GitHub パブリックコミットの4%を生成（前月比2倍）。ARR も Anthropic が $30B で OpenAI の $24B を上回り、複数の指標で逆転が鮮明になった。

2026-05-13 公開 | Sources: Axios, VentureBeat, eWeek, Ramp AI Index
