🔍 主要な発見

✅ 推奨: twscrape（アカウント認証型スクレイパー）

公式APIキー不要で、@umbrella_bowl のログイン情報で認証して動くPythonライブラリ。フォロータイムライン・検索・ユーザーツイートが取得可能。Windows bash 対応、2025年現在アクティブメンテ中。

pip install twscrape ｜ GitHub: vladkens/twscrape

⚠️ 公式API無料枠はほぼ書き込み専用

X API v2 の無料枠はタイムライン読み取りが制限されており、Basic プラン（$200/月）以上が必要。調査用途での利用は非現実的。

⚡ twscrape 基本操作

pip install twscrape

# @umbrella_bowl のアカウント情報を追加
twscrape add_accounts accounts.txt username:password:email:email_password

# ログイン確認
twscrape login_accounts

# フォロータイムライン取得（20件）
twscrape timeline_by_login "umbrella_bowl" --limit 20

# 特定ユーザーのツイート取得
twscrape user_tweets "OpenAI" --limit 50

⚠️ 運用上のリスク

リスク内容対処
アカウント制限 リクエスト過多でBANリスク 30分〜1時間おきに制限。調査専用アカウントなので影響は最小
認証情報管理 パスワードをファイルに持つ必要 accounts.txt を .gitignore 対象に設定。.env での管理が安全
仕様変更リスク X の変更で twscrape が壊れる可能性 pip install -U twscrape で定期更新
取得範囲の限界 非公開アカウントは取得不可 調査対象を公開アカウントに絞る
