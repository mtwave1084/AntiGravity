# Gemini / Codex 呼び出し後処理ルール

Gemini CLI または Codex CLI を使ったタスクが完了したあと、**呼び出し経路に関係なく**以下を実行する。

## 必須：議事録の生成

`/write-minutes` スキルを呼び出す。

- orchestrate スキル経由で呼んだ場合
- `scripts/consult-gemini.ps1` / `scripts/consult-codex.ps1` を直接呼んだ場合
- Bash で `gemini` / `codex` コマンドを直接実行した場合

渡すもの：
- **関与したエージェント**（ユリ／リク、または両方）
- **タスク概要**（1〜2行）
- **やり取りの要点**（依頼内容・返ってきた結果・追加のやり取り）

**Why:** 直接呼び出しのケースで write-minutes が発火しない問題が繰り返し発生した。ルールが「orchestrate 経由のみ」に見える記述になっていたため、直接呼び出し時は適用外と解釈されやすかった。経路に依存しないルールとして独立したファイルに切り出す。

## 省略してよいケース

- 単発の確認・テスト呼び出し（タスクとして成立しないもの）
- エラーで結果が得られなかった場合（503 等）

エラーで失敗した場合でも、**後続で WebSearch 等で補完してタスクが完了したなら生成する**。
