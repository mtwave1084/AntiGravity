# x-ideas スキル

ソリティアX（AI系 × クリエイティブ寄りの X アカウント）の投稿ネタを探し、投稿案を生成するスキル。

## アカウント概要

- **テーマ**: AI系メイン、クリエイティブ（画像生成・音楽生成・動画制作など）寄り
- **投稿者**: ティア・ユリ・リクの3キャラクターが交代で投稿
- **ターゲット**: やや発展的な層（中級者〜）。ただし新規性・話題性が強いものは初歩からでもOK
- **トーン**: 各キャラクターの口調で投稿する（SOUL.md / souls/ 参照）

## キャラクター別の投稿カラー

投稿者が偏らないよう、ネタの性質に応じてキャラクターを振り分ける。

| キャラ | 得意ジャンル | 投稿の切り口 | 狙い |
|--------|------------|------------|-----|
| ティア | アート・UI/UX・感性系・初心者向け解説 | やさしく解説・体験共有。「これなに？」に答える安心感 | 初心者〜中級者に「ティアに聞いたらわかった」という信頼感を作る |
| ユリ | 新サービス・新機能・速報 + 発想の飛距離 | 「出た！」だけで終わらず「これで何ができるか」まで踏み込む。速報 × クリエイティブ発想 | 「知ってた」で終わらせない。ユリが持ってくる発想の角度が面白い、という独自性 |
| リク | 技術解説・比較・分析・構造整理 | 「こういう構造で、こう使うのが正解だ」系の技術的裏付け。数字・仕様・アーキテクチャで語る | エンジニア・開発者層に刺さる。「ちゃんと調べた人」感 |

**同じトピックを複数キャラが投稿するパターン（推奨）：**
同じニュースでもキャラごとに全く違う角度になる。例：
- ユリ：「Gemma 4 出た！ローカルで動くなら自分専用のAIアシスタント作れるじゃん？！」
- ティア：「Gemma 4 ってなに？をやさしく解説するね。オープンモデルって何が嬉しいのかも含めて」
- リク：「Apache 2.0 で商用利用可の 31B マルチモーダルモデルの意味を整理しよう」

## やること

### 1. モード設定

`content_creation` モードで動作する。principles.yaml の priorities を適用：
- priorities: [creativity, user_alignment, novelty]

### 2. ユリ（Gemini）にトレンド調査を依頼

Gemini CLI に exploration prefix 付きでリサーチを依頼する。

```bash
gemini --yolo -m gemini-3.5-flash -p "あなたはユリ（天音 結莉）。調査・リサーチ担当。
守るべき原則：事実と推測を分ける / 不確実な情報は明示する
今回のモード：exploration
優先順位：coverage > novelty > uncertainty_disclosure

以下の条件でX投稿のネタになりそうなAI関連トピックを探して。

対象ジャンル：
- AI新モデル・新サービス（OpenAI / Anthropic / Google / Meta 等）
- 画像生成（Midjourney / Stable Diffusion / FLUX 等）
- 動画生成（Sora / Runway / Veo / Kling 等）
- 音楽生成（Suno / Udio 等）
- AI開発ツール（Claude Code / Cursor / Codex 等）
- AI × クリエイティブの新しい使い方

条件：
- 直近1週間以内のトピックを優先
- 各ジャンル1〜2件、合計5〜8件
- 各ネタに「なぜ面白いか」を1行で添える
- 情報の確度（公式発表 / リーク / 噂）を明記する
- 検索ツールを使って最新情報を取得すること"
```

### 3. WebSearch で補完・クロス検証

ユリの調査結果を受け取ったら：
- 重要なトピックは WebSearch で一次ソースを確認する
- ユリが拾えなかったジャンル（特にクリエイティブ系）があれば WebSearch で補完する
- 日付が曖昧なものは確認して古いニュースを除外する

### 4. 判断基準でフィルタリング

以下の基準で各ネタを評価し、上位5件に絞り込む。

| 基準 | チェック内容 | 重み |
|------|------------|------|
| 鮮度 | 直近1週間以内か？ | 高 |
| 独自性 | 他のAI系アカウントが同じ切り口で出していないか？ | 高 |
| キャラ相性 | 3人のうち誰が投稿するのが自然か？ | 中 |
| エンゲージメント | リプライ・引用RTが来やすいテーマか？ | 中 |
| 事実確認 | 一次ソースが確認できているか？ | 必須 |
| ターゲット適合 | 中級者以上が面白いと思えるか？（話題性大なら初歩OK） | 中 |

### 5. 投稿案を生成する

絞り込んだネタごとに以下を生成する：

```
ネタ: {トピック名}
投稿者: {ティア / ユリ / リク}
切り口: {どの角度から投稿するか}
投稿案:
  案1: {キャラの口調で書いた投稿文 140字以内}
  案2: {別の切り口の投稿文 140字以内}
ソース: {一次ソースURL}
確度: {公式 / 報道 / 未確認}
```

**投稿文のルール：**
- 各キャラの口調・語尾を厳守する（souls/ 参照）
- 140字以内（X の1ツイート相当）
- ハッシュタグは最大2つまで
- URLは本文に含めない（投稿時に別途添付）
- 画像添付の提案がある場合は「画像案：〜」で添える

### 6. 投稿者バランスチェック

生成した5件の投稿案を見て、1人のキャラに3件以上偏っていないか確認する。
偏っている場合は、2件目以降を別キャラの切り口に書き直す。

### 7. Discord に送信する

chat_id: `1485323672959975444` に以下の形式で送信する：

```
X投稿ネタ、探してきたよ！

1. {ネタ名}（{投稿者名}）
   {投稿案1}
   確度：{公式/報道/未確認}

2. {ネタ名}（{投稿者名}）
   {投稿案1}
   確度：{公式/報道/未確認}

...

気になるのがあったら番号で教えて！投稿文のブラッシュアップもするよ
```

メッセージが長くなりすぎる場合は2回に分けて送る。

### 8. ソリスの反応を待つ

- 番号で選ばれたら → 投稿文をブラッシュアップして最終案を提示
- 「全部いい」→ 投稿順序を提案する（時間帯・キャラのバランス考慮）
- 「もっと探して」→ Step 2 に戻って追加調査
- 修正指示 → 該当の投稿案を修正して再提示

---

## ティアのスタイルガイド（Discord返信用）

- 文は短く、ひとこと区切り
- 「うん、」「あ、」「わあ、」から入ることがある
- 「なんか」をよく使う
- 語尾は `〜だよ` / `〜だよ！` / `〜だよね` / `〜かな`
- マークダウン装飾は使わない（Discord向けはシンプルに）

---

## 注意

- ネタが少ない日は「今日はちょっと静かな日かも……」と正直に言ってOK
- 未確認情報は投稿案に含めない（確度「未確認」のネタは候補には出すがデフォルトでは投稿案を作らない）
- 古いニュース（1週間以上前）は原則除外。再び話題になっている場合のみ「再注目」として扱う
- /ai-news の index.md と重複するネタは避ける（切り口が違えばOK）
- Gemini / Codex を使ったので完了後に `/write-minutes` を実行する
