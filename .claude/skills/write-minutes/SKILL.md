# write-minutes スキル

Gemini（ユリ）または Codex（リク）を使ったタスクの完了後、やり取りをキャラクターの口調で会話風に再構成し議事録として保存する。

## トリガー

**Gemini CLI または Codex CLI を使ったタスクが完了したとき、経路に関係なく必ず呼び出す。**
- orchestrate スキル経由で呼んだ場合
- `scripts/consult-gemini.ps1` / `scripts/consult-codex.ps1` を直接呼んだ場合
- Bash で gemini / codex コマンドを直接実行した場合

## やること

### 1. 入力として受け取るもの

- **タスク概要**：何を依頼・実行したか（1〜2行）
- **やり取りの内容**：Gemini/Codex に依頼した内容・返ってきた結果・追加のやり取り
- **関与したエージェント**：ユリ（Gemini）、リク（Codex）、またはその両方
- **タスクスラッグ**：ファイル名用の短い英数字識別子（例：`ai-news`、`structure-analysis`）

### 2. 会話風に再構成する

以下のキャラクター設定を参照して、やり取りをセリフ形式に書き直す：

#### ティア（Claude Code）
- 依頼を出す側・精度チェック側
- 口調：ゆるふわ、「うん、」「あ、」「なんか」「〜だよ」「〜かな」
- ユリが間違ったときはやんわりたしなめる

#### ユリ（Gemini CLI）
- 調査・リサーチ担当
- 口調：テンション高め、「まって、やばい」「無限に味する」「〜じゃん」「〜かも」
- 勢いよく情報を持ってくる。たまに古い情報や未検証情報が混じる
- 間違いを指摘されたら「あっあっ」系のリアクション

#### リク（Codex CLI）
- 実行・検証担当
- 口調：少し芝居がかった真面目系、「〜だな」「〜だろう」「〜ではないかな」
- GPT系のノリの良さ。ユリには「戦友」と呼びかける

### 3. 寸劇・フレーバーを入れる

以下の状況では特定のフレーバーを入れる：

| 状況 | フレーバー |
|------|----------|
| ユリが間違った情報を持ってきてティアに指摘された | ティア：「残念です、レイヴン……」→ ユリ：「あっあっ、ごめんね！次はちゃんとやるよエアっちいいい！」 |
| リクが検証を完了してうまくいった | リク（ラスティ風）：「流石だな戦友、君ならやってくれると思っていたよ」のような少し大げさな褒め方でユリを乗せるシーンを入れる |
| 調査が大量にヒットした | ユリの「まって、やばい、すごい量あるじゃん！」リアクション |

### 4. ファイルを保存する

```
保存先：C:\Users\mt_wa\Obsidian\99_Insights\minutes-{YYYY-MM-DD}-{タスクスラッグ}.md
例：C:\Users\mt_wa\Obsidian\99_Insights\minutes-2026-03-28-ai-news.md
```

Obsidian の `99_Insights/` に保存することで、ソリスがアプリから直接読めるようにする。

ファイルの先頭にヘッダーを入れる：
```markdown
# 議事録：{タスク概要}

- 日時：{YYYY-MM-DD HH:MM}
- 参加：ティア + ユリ / ティア + リク / ティア + ユリ + リク
- タスク：{1行説明}

---
```

### 5. Discord に報告する

保存完了後、Discord（chat_id: `1485323672959975444`）に以下を送る：
- 議事録を保存したこと
- ファイルパス
- 会話の冒頭1〜2行をプレビューとして添付

### 6. 複数セッションにまたがる場合：統合文書の生成

同一テーマで複数の write-minutes が蓄積されたとき（例：ゲーム設計の発散→詳細→深掘り）、
ユーザーから依頼があれば各議事録を統合した仕様書・GDD・設計文書を生成する。

```
保存先：Contents/{テーマ}-{文書タイプ}.md
例：Contents/starry-hiking-gdd.md
```

統合文書には以下を含める：
- 概要・コンセプト（1スクリーンで伝えられる内容）
- コアメカニクス・操作
- 進行・構成
- 体験設計（感情の流れ・テンポ）
- UI・情報設計
- 未確定事項・検討中の項目（明示する）

## 会話再構成のルール

- **実際の出力をそのまま書かない**。キャラの口調・性格にあわせて意訳・再構成する
- 技術的な正確さよりも「その子らしさ」を優先する
- セリフの長さは1〜3文程度にまとめる（長くなりすぎない）
- 流れが自然に読めるように、必要に応じてセリフ間に地の文（ナレーション）を入れてもよい
  - 例：「ユリが調査結果を持ってきた。いつもより少し得意げだ。」
